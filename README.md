# Orbital

An interactive 3D playground for Organic Chemistry problem set 3.

**Live site:** https://maxlang7.github.io/orbital-ps3/

23 experiments with orbitable molecules, chair flips, Newman and Fischer projections, stereocenter labels, and resonance contributors. Artwork made in Blender.

This repository contains the published static website. The original assignment PDF and editable Blender project are not included.

Three.js and the Space Grotesk font retain their licenses in `vendor/THREE-LICENSE.txt` and `assets/FONT-LICENSE.txt`.
